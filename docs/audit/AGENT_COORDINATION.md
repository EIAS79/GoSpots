# Agent coordination board

**Purpose:** Prevent parallel agents from stomping the same files / half-reverting each other’s logic.

**Rules (mandatory for every subagent):**
1. Before editing, claim your lane below (add row under **In progress**). If a file is locked by another lane, **do not touch it**.
2. Own only the files listed in your lane. Docs: you may append to `GO_SPOTS_IMPLEMENTATION_REPORT.md` and update this board; prefer [`docs/PRODUCTION_STATUS.md`](../PRODUCTION_STATUS.md) for operator status over rewriting large history docs.
3. No `prisma migrate reset`. No new migrations unless the lane explicitly allows it.
4. When done: move your row to **Completed**, clear file locks, note verify commands.
5. Prefer **extend** existing helpers over rewriting hot services.
